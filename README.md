## About Arcadia

Arcadia is a Windows desktop application for executing Roblox Lua scripts while keeping script management and execution controls in one compact workspace. Its desktop-oriented design targets Windows 10 and Windows 11, providing a straightforward interface alongside the core tools needed to run scripts.

The executor is built around a no-key process and includes batch execution, a queue that persists between sessions, and an integrated debugger. Auto-update functionality and access to a 500+ script hub are also included, helping Arcadia remain useful as Roblox scripts and usage patterns change during 2026.

**What distinguishes Arcadia from other Roblox executors?**

**Are scripts saved on the local computer?**
